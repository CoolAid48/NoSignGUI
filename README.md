### Allows you to toggle the sign text interface off and on!

## More Details Below:
- **This is especially useful when using a lot of empty signs for building**
- **Toggle Keybind is `G` by default**
- **Inspired by [Masonion's NoSignGUI](https://modrinth.com/mod/nosigngui) mod, for versions <1.21.4**
- **Functions fully client-side, and also works with Hanging Signs!**
